    How it works and what is stored

    Web Crypto generates 32 random bytes. An 8-bit SHA-256 checksum is appended to the entropy: the resulting 264 bits form 24 indexes into the 2048-word BIP39 list.

    This file makes no network requests and writes no cookies, files or localStorage data. The phrase remains in memory until you clear it, generate a new phrase or leave the page. Hiding words does not remove them from memory; browsers cannot guarantee secure memory erasure.

    Words are hidden when the tab becomes hidden or after one minute. Page printing is disabled. The checksum verifies the format, not device security or compatibility with every wallet.

    Open the downloaded file in a modern browser. If Web Crypto is unavailable, generation is blocked; no alternative random generator is used.
